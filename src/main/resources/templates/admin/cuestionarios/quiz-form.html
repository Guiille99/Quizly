Ver estructura JSON requerida

Incluye título, preguntas y opciones. La asignatura, el tema y la dificultad se seleccionan aquí. Se admiten SINGLE_CHOICE (2 a 4 opciones) y TRUE_FALSE (Verdadero y Falso, en ese orden). Cada pregunta debe tener exactamente una respuesta correcta. 

{
    "titulo": "Cuestionario de ejemplo",
    "descripcion": "Descripción opcional",
    "preguntas": [
    {
      "enunciado": "¿Cuál es la respuesta correcta?",
      "tipoPreguntaCodigo": "SINGLE_CHOICE",
      "opcionesRespuesta": [
        {"texto": "Opción A", "correcta": true, "retroalimentacion": "Correcto"},
        {"texto": "Opción B", "correcta": false}
      ]
    }
    ]
    }

Límites: título 100, descripción 255, enunciado y opción 255, retroalimentación 500 caracteres. Archivo máximo: 2 MB.
